СНИМКИ ЗА ПРЕЗЕНТАЦИЯТА
=======================

Тези снимки вече са поставени (от твоите екрани). За да смениш някоя, просто
запази нов PNG със същото име.

Файл                 ->  Слайд / екран
---------------------------------------------------------------
dashboard.png        ->  Табло на треньора (десктоп начало)
attendance.png       ->  Присъствие (мобилен екран, с бадж „Извинение от родител“)
schedule.png         ->  Месечен график (календар)
fees.png             ->  Месечни такси (списък състезатели)
yearly-program.png   ->  Годишна програма БФВ (мезоцикли)
textbook.png         ->  Учебник БФВ (методика)
ai-generator.png     ->  AI генератор на тренировки
training.png         ->  Готова тренировка с упражнения
articles.png         ->  Статии и методика (списък)
forum.png            ->  Форум за треньори
parent-home.png      ->  Родителски портал — Начало
room-home.png        ->  Отборна стая — Начало
room-schedule.png    ->  Отборна стая — График
room-chat.png        ->  Отборна стая — Чат
(по желание, не се ползват в момента)
room-profile.png     ->  Отборна стая — Профил

Където липсва файл, на слайда се показва сива рамка с указание кой екран да
заснемеш. PNG е за предпочитане.
